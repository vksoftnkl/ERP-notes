## Summary
Counted over the 47 rows below: **YES 9, PARTLY 20, DIFFERENT 8, NO 10**.
The screen has the right *engine* (server calc painted back, chips, item strip, F12 dialog, charges grid) but the *frame* is not the mockup:
the header is a 4x4 field block with different fields, the totals are ONE text line, there is no WARN/REFUSE strip, the F12 panels are a modal dialog, and the grid shows engine columns the mockup hides while lacking the ones it shows.

### The 10 biggest gaps
1. **TOTALS panel is one rich-text line**, not the boxed panel (Taxable, GST, Charges on bill, Supplier TCS, Round off, Net payable, Invoice amount printed, Difference with check mark, Off-bill, Short qty parked, GST on short qty, Cash mode). Qt only: the server already returns every figure (`totals.*`).
2. **No WARN / REFUSE strip with the "override (logged)" tick.** Warnings come back from the server (`warnings[]` with code/message/field) but are shown in a modal box after save; refusals go to a one-line hint + modal. The RATE_ABOVE_PO / SHORT_QTY / SERIAL_COUNT live warnings do not exist as validate-time rows. Qt for the strip; server for live codes RATE_ABOVE_PO and SHORT_QTY (only SERIAL_COUNT, INVOICE_AMOUNT_MISMATCH and the duplicate-bill warning exist) and for an override flag.
3. **Header fields missing:** Bill from (supplier GSTIN / branch), Mode (Credit/Cash), Credit days + due date, Source, Goods received (date), Agent, Place of supply, Reverse charge, IRN / Ack, Transport. DTO has `mode`, `creditDays`, `goodsReceivedOn`, `irn`, `ackNo` (Qt only for those); Agent, Reverse charge, Bill-from, Transport are not in the header DTO (server). DB has `pi_agent_id`, `pi_is_reverse_charge`, `pi_pos_stcd`, `pi_due_date`, `pi_msme_due_date`, `pi_supplier_gstin`; no transport column on `pur_invoice`.
4. **F12 BATCHES + SERIALS are a modal dialog, not inline side-by-side panels** under the lines. The dialog lacks the mockup's Lot (new/existing) column, Status column (DUPLICATE - scanned twice chip), the per-panel headings ("F12 - BATCHES (line 3)", "SERIALS (line 6, scan mode)"), and one dialog shows only one of the two at a time.
5. **Line grid columns differ from the mockup.** Mockup order: # Barcode Item Unit Batch/Serial Expiry Billed Recd Dmg Short Free Rate Disc Taxable GST% ITC Tax Total Cost-w/o Markup% Sell A MRP Check. Built (default view): Barcode Item Unit Batch/Serial Expiry Billed Recd Dmg Short Free Rate Disc% **Sch%** Taxable GST% ITC Tax Total Cost-w/o **Cost incl.** MRP **Extra disc** Check (+ PO/GRN, hidden in the snapshot). Markup% and Sell A are hidden unless purchase.allow_price_update is on (they are in the mockup's default view); Sch%, Cost incl., Extra disc, PO/GRN should be behind "More columns".
6. **No "More columns" chooser row** (Gross, Disc Rs, Cess %, Cess/unit, Mfg date, Godown, Weight, Sell B/C/D, Old prices, PO/GRN ref, Remarks). Qt only (a column chooser on NexTable; saved per user).
7. **Check column** only says OK / SHORT n / REJECTED n. Missing: RATE +x% LAST / RATE +x% PO, NEW MRP n, PRICE KEPT, "n / n SN" serial count. Qt (RATE and NEW MRP need item-context or last-purchase data already on the strip route; PRICE KEPT needs a server flag per line: `pii_price_update_result` exists in DB, check whether /get returns it).
8. **Button rows wrong.** Mockup row 1: From GRN / PO Ctrl+L, Sister company bill, Batches/serials F12, Attach Ctrl+A, Return from bill Ctrl+F11, Pay this bill Ctrl+F8. Row 2: New, Hold F9, Save Draft, Post, Edit F2, Cancel, History, Show List, Close. Built: row 1 only Batches/serials, Payment hold, Sister company bill, in one line with row 2; Attach / Return / Pay / From GRN-PO have shortcuts (Ctrl+A, Ctrl+F11, Ctrl+F8) but NO buttons; Hold F9 is a "Payment hold..." button without the key label; an extra Print Ctrl+P is shown. Two separate rows are not drawn. Qt only.
9. **Charges grid columns:** mockup Charge, On bill, Basis, Rate, Amount, Payee, **Into cost**, GST. Built: Charge, On bill, Basis, Rate, Amount, Payee, GST, **Net** (no "Into cost"; Net is extra). The "add charge..." prompt and the "charge_master rows only" sub-title are missing. Qt (Into cost needs a server field if not in validate charges[]).
10. **Header cards / frame:** no card heading "THE HEADER" / "THE LINES" / "CHARGES" / "TOTALS" section titles, no supplier-name panel, no "Acme Foods . Coimbatore" subtitle; the title is plain text and the DRAFT chip is a plain label (no coloured chip). The totals/charges frame order differs: mockup puts Charges (left) and Totals (right) side by side; built stacks them.
