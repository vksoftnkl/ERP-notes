User 2026-10-23: customers claim "I didn't change this rate"; wants every item_price_master change in a SEPARATE log (item, company, branch, user, time, device, all fields) and a detailed DATE-WISE report to show the user.

**Why not audit.audit_log:** price rows there (only since 21/22 Oct, ~120, mostly tests) have NULL log_branch_id / log_device_name / log_entity_id, no company column, labels not columns, mixed tables; and `price-bucket.service.ts rekeyItem` writes ipm with NO audit at all.

**Plan:** `/home/vk/Shared/Prathap/inventory/plan-price-change-log.md` + `plan-price-change-log_mockup.{py,png}`. Table `inventory.item_price_change_log` (one row per price row per save, change_set_id, IPM + IQP, before/after jsonb + changed[] + generated old/new price A/MRP/cost, names snapshotted, user/device/ip/app from token/context never body, append-only via REVOKE). No trigger (user rule, [[sql-vs-nestjs-rule]]) → ONE `PriceMasterWriter` every write goes through + guard test + "changed outside the log" gap count on the report. Sources ITEM_CARD / CHANGE_SELLING_PRICE / QTY_PRICE / BUCKET_REKEY / IMPORT. Routes /item-price-log/list|get|days|item-history. Qt report: filters, day strip, grid grouped by date with change chips, Enter = Before|After|Change popup, F3 item history, CSV + print. No backfill.
