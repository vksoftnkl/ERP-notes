Additional charges live in `tblCharges` driven by `ChargeGridController` (src/shared/charges). Confirmed design (user-approved, mirrors Tally's assessable-value model):

- **Method → charge Amount**: FIXED (lump = Rate), QTY (`billQty×rate`), NET_QTY (`netQty×rate`), KG/QTL/TON (`weight×rate`), PERCENT (`NetGross×rate/100`). `chg_apply_on` (QTY/VALUE/WEIGHT/FLAT) ONLY matters for FIXED — it's the distribution basis for the lump sum (FLAT=equal, residue→last line). The other methods compute each line's share directly.
- **before_tax=1** → share goes into the item line's taxable base and is taxed at that LINE's own GST rate (charge's own ledger rate ignored). Cash disc = a before-tax DEDUCT charge. User-confirmed 2026-07-28: `before_tax` ALONE decides this — `tax_apl` is irrelevant on a before-tax row (it only governs after-tax rows), because the taxable-base move already taxes the charge at the item rate.
- **after_tax + tax_apl=1** → charge carries its OWN GST (ledger rate) as a separate tax → header tax + bill. **after_tax + tax_apl=0** → flat add to line total, no tax.
- A charge row's own GST is therefore computed iff `tax_apl && !before_tax`; every other combination zeroes the row's WHOLE tax block **including Tax %** (user-confirmed: no showing "18%" beside zero tax; `cd_tax_perc` saves as 0). Hsn/SAC snapshot is kept. Charges never carry cess (no cess rate in the ledger snapshot, `DistributeResult::cess` stays 0).
- **Manual Amount override** (user-confirmed 2026-07-28): typing a charge row's Amount zeroes its Rate — "the user decided not to use the rate". `distribute()` reads rate==0 && amount!=0 as operator-priced and spreads that amount by ApplyOn instead of recomputing from the method (round-trips through save: `cd_rate`=0 + `cd_amount`). Keying a Rate again flips back to rate-driven. Rate is NOT editable on FIXED rows (priced by Amount); rate-driven rows paint a unit suffix (% /Qty /NetQ /Kg /Qtl /Ton) at paint time only — never in the cell text, which must stay a bare number.
- ADD/DEDUCT = sign. Two signed per-line item columns: `ChrgBeforeTax`, `ChrgAfterTax` (QuoteItemCols 87/88; `NetGross`=86).
- **Value basis by row (user-confirmed 2026-07-29)**: every row is measured against `NetGross` EXCEPT a **DEDUCT row that is NOT before-tax** — a discount off the already-taxed bill — which is measured against each line's **net total** (goods + before-tax charges + GST/cess + after-tax ADDs). Affects PERCENT and ApplyOn=VALUE proration. So `distribute()` runs two ordered passes and takes a third arg `NetTotalFn netTotalOf(shares)` — the host writes pass-1 shares into its lines, taxes them, returns each line's Total. Omitting it = old single-basis behaviour (sales/purchase until migrated). Multiple after-tax discounts all measure the same pre-discount net total (no compounding, order-independent).

**The engine**: `ChargeGridController::distribute(lines, roleOverrides)` — host passes each item line's `LineBasis{netGross,billQty,netQty,weight}`, gets back per-line `{beforeTax,afterTax}` + doc-level `{chargeTaxable,cgst,sgst,igst,cess}`. `roleOverrides` (role→per-line amounts) lets the KEPT weight-band distance-freight engine feed FREIGHT/LOADING without being re-flattened.

**Pipeline** (recalcDocumentTotals, non-circular single pass): Pass 1 `priceRowGoods`→NetGross → build LineBasis[] + freight/loading overrides → `distribute()` → write ChrgBeforeTax/AfterTax → Pass 2 `finalizeRowWithCharges` (Taxable=NetGross+ChrgBeforeTax, GST at line rate, Total=taxed+ChrgAfterTax) → totals. `TaxableAmt` col is now POST-charge.

**Grid Y/N flag trap** (bit us 2026-07-28, watch for it when replicating to sales/purchase): NexTable flag columns are Text cells written as "Y"/"N" (fetchItemPrice). `QVariant::toBool()` reads BOTH as true ("N" is a non-empty string that isn't "0"/"false"), so flags must be compared against "Y" — `QuotationEntry::isRowFlagSet(row, col)`. IsInclusiveTax was silently always-true in both pricing paths and in the save payload's `sqiIsTaxIncl` until this was fixed. `ServiceItem` escapes it only because it's written from a JSON bool ("true"/"false").

**Invariant**: Bill = HeaderTaxable + HeaderTax + after-tax-flat(tax_apl=0) charges = Σ lineTotal + after-tax charges' own GST.
